- [ ] **변경되거나 합성된 콘텐츠: 예**

- [ ] 썸네일 `output/thumbnail.png` (법무 확인 후)
- [ ] 카테고리 교육, 언어 한국어, 재생목록 '유체역학 (대학 공학)'
- [ ] 공개 범위: **비공개 또는 예약 공개로 먼저 올림**(권장). 사용자 최종 확인 뒤 공개 전환
- [ ] 공개 뒤 고정 댓글 등록, 챕터가 표시되는지 확인

### 유튜브 Shorts (`shorts_vertical.mp4`)
- [ ] 제목, 설명(첫 줄 보충 메모, AI 고지, 본편 링크), 해시태그 3개
- [ ] **변경되거나 합성된 콘텐츠: 예**
- [ ] **아동용: 아니요**
- [ ] 관련 동영상에 본편 지정
- [ ] 공개 범위: 본편보다 먼저 공개하지 않는다. 비공개로 올려 두고 본편 공개 뒤 공개(권장)

### 인스타그램 릴스 (`shorts_vertical.mp4`) / 피드 (`shorts_square.mp4`)
- [ ] 캡션 입력, 해시태그 5개
- [ ] 게시 화면 고급 설정에서 **"AI 정보(AI 레이블)" 켬** (릴스, 피드 모두)
- [ ] 프로필 링크에 본편 URL
- [ ] 예약 게시 또는 본편 공개 뒤 게시(권장)

### 틱톡 (`shorts_vertical.mp4`)
- [ ] 캡션 입력, 해시태그 4개
- [ ] 게시 설정에서 **"AI 생성 콘텐츠" 토글 켬**
- [ ] 프로필 링크에 본편 URL
- [ ] 본편 공개 뒤 게시(권장)

### X / 페이스북 (`shorts_square.mp4`)
- [ ] 게시글 입력, `[본편 링크]`를 실제 URL로 교체, X는 280 이내 재확인
- [ ] 두 플랫폼 모두 게시물에 AI 영상 고지 문구가 들어 있는지 확인(페이스북은 메타 'AI 정보' 표시 옵션이 보이면 켬)
- [ ] 본편 공개 뒤 게시

- 화면 안 AI 배지는 플랫폼 라벨을 대신하지 않는다. 두 가지를 모두 한다. 각 플랫폼 정책 원문은 법무팀도 열람하지 못했으므로 **업로드 시점에 설정 화면에서 다시 확인한다**(법무 2차).
